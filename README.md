## 📌 Project Overview
This project presents an end-to-end **Healthcare Analytics Dashboard** built using **Power BI**, analyzing 5,000 patient records to uncover insights related to patient demographics, hospital performance, and treatment costs.

## 🎯 Objectives
- Analyze patient demographics and admission trends
- Evaluate department and doctor performance
- Track healthcare costs and financial metrics
- Enable data-driven decision-making for hospital management

## 📊 Dashboards Included
1. Hospital Overview
2. Patient Demographics & Trends
3. Cost & Financial Analysis
4. Department Performance
5. Doctor Performance

## 🧮 Key Metrics (DAX)
- Total Patients
- Average Length of Stay (LOS)
- Cost per Patient
- Average Daily Treatment Cost
- Maximum Treatment Cost

## 🛠 Tools & Technologies
- Power BI
- DAX
- Data Modeling
- Data Visualization
- Healthcare Analytics

## 📁 Dataset
- Synthetic healthcare dataset with 5,000 patient records
